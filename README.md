# 팀 점심 현황

팀원들의 점심 상태(같이/따로/외근·휴가)를 한눈에 보는 사내 웹서비스예요.

> **주의**: `config.json`(팀 코드·팀즈 주소)과 `lunch.db`(팀원 기록)는 GitHub에 올리지 않아요. 저장소에는 `config.example.json`만 있어요.



## 1. 준비 (처음 한 번만)
1. https://nodejs.org 에서 **LTS(권장) 버전**을 내려받아 설치해요. (버전 22.13 이상이면 돼요)
2. 이 폴더(team-lunch)를 서버로 쓸 컴퓨터에 복사해요.
   - **이 컴퓨터는 점심 전에 항상 켜져 있어야 해요.** (팀원 모두가 이 컴퓨터로 접속해요)

## 2. 설정
먼저 `config.example.json`을 복사해서 이름을 `config.json`으로 바꿔주세요.
`config.json` 파일을 메모장으로 열어 수정해요.
- `teamCode`: 팀원들이 처음 접속할 때 입력하는 코드예요. 꼭 바꿔주세요.
- `deadline`: 변경 마감 시간이에요. (지금은 11:25)
- `teamsWebhookUrl`: 팀즈 알림 주소예요. (아래 4번 참고, 지금은 비워둬도 돼요)
- `members`: 팀원 이름 목록이에요.

## 3. 실행
- **Mac (권장)**: `시작하기.command`를 더블클릭해요.
  - 처음에 "확인되지 않은 개발자" 경고가 뜨면, 파일을 **우클릭 → 열기 → 열기**를 눌러주세요. (한 번만 하면 돼요)
  - 그래도 안 열리면 터미널에서 `chmod +x 시작하기.command`를 입력한 뒤 다시 시도해요.
  - 서버가 켜져 있는 동안 Mac이 잠자기에 들어가지 않도록 `caffeinate`가 같이 실행돼요. 노트북이면 뚜껑을 닫지 말고, 전원을 연결해두세요.
  - "수신 연결을 허용하시겠습니까?" 창이 뜨면 **허용**을 눌러주세요.
- **Windows**: `시작하기.bat`을 더블클릭해요.

검은 창에 "팀원 접속 주소: http://숫자.숫자.숫자.숫자:3000"이 나와요.
**이 주소를 팀원들에게 알려주면 돼요.** 이 창을 닫으면 서버도 꺼져요.
(같은 사내 네트워크에서만 접속돼요. 주소의 숫자는 재부팅 후 바뀔 수 있으니, 바뀌면 새 주소를 다시 공유해주세요.)

## 4. 팀즈 알림 연결 (선택)
1. 팀즈 왼쪽 메뉴에서 **Workflows** 앱을 열어요.
2. "웹후크 요청을 받으면 채널에 게시" 템플릿을 선택해요.
3. 알림을 받을 팀과 채널을 고르면 **웹후크 주소(URL)**가 만들어져요.
4. 그 주소를 `config.json`의 `teamsWebhookUrl`에 붙여넣고 저장해요. (따옴표 안에)
5. 서버를 껐다 켠 뒤, 터미널에서 `node server.js --test-teams`를 실행하면 시험 메시지가 가요.
이후에는 **평일 11:25에 자동으로** 오늘 점심 인원이 채널에 올라가요.

## 5. 데이터
모든 기록은 `lunch.db` 파일 하나에 저장돼요. 이 파일을 복사해두면 백업이 돼요.
